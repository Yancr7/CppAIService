# C++ AI 应用服务平台

## 项目简介
本项目是基于 C++ 开发的轻量级 AI 应用服务平台，自研 HTTP 框架作为基础支撑，整合多模型对话、RAG 检索增强、消息队列异步处理等核心能力，实现了高可用、可扩展的 AI 对话服务后端。

## 技术栈
- 开发语言：C++11/14
- 核心模块：
  - `HttpServer`：自研 HTTP 服务端，支持高并发请求处理与响应
  - `AIApps`：AI 应用核心逻辑，封装多模型对话、会话管理、工具调用
  - 依赖技术：JSON 解析、多线程并发、消息队列异步处理

## 核心功能
1.  **多模型对话交互**：支持主流大模型接入，实现多轮对话、上下文管理与会话多租户化
2.  **RAG 检索增强**：内置检索模块，支持知识库问答与上下文增强，提升对话准确性
3.  **异步任务处理**：通过消息队列实现请求异步化，提升服务吞吐量与稳定性
4.  **模块化扩展**：采用策略模式+注册工厂设计，支持快速接入新模型、新工具，降低耦合度

## 项目亮点
- 自研 HTTP 框架，无重型第三方依赖，性能轻量高效，适合作为 AI 服务后端
- 架构分层清晰，网络层与业务层解耦，代码可维护性与扩展性强
- 完整的工程化实现，覆盖并发处理、异常管理、工具调用等 AI 服务核心场景
